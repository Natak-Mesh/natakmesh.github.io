ION TAK Server  /  Appliance

ION TAK Server

A mini-PC that boots straight into a configured, official TAK Server. It's for teams that already have a network connection and want a TAK server of their own.

Your team reaches it privately over Tailscale from any internet connection. It doesn't use a public cloud service, and it doesn't need a Nucleus.

02Which one

ION TAK Server or Nucleus

They're separate products. The ION TAK Server is for teams that already have a network connection. Nucleus is a mesh radio for places with no network: it builds its own WiFi and LoRa mesh between units.
