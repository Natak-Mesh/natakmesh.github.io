Field tests

What we measured, where, and on which hardware. Every result here is a single link between two or three nodes. A mesh with more nodes reaches further.

Most of these tests ran on earlier hardware (versions 1.0 to 1.2) with a 159 mW LoRa radio. Version 3 has a 500 mW WiFi radio and a 1 W LoRa radio. We'll add version 3 results here as we measure them.

WiFi and LoRa in an apartment complex

How far the WiFi mesh and LoRa reach between buildings, with no nodes in between to give line of sight.

Setup

  • Node 0023, fixed: on a second-floor balcony, with a yogurt-cup antenna (FIG. 01).
  • Node 0022, mobile: stock antennas, carried in a pack (FIG. 02).
  • Site: apartment complex built in 2014, large units of about 1,000 ft² (FIG. 03).
  • LoRa: both radios disconnected from the Nucleus and set to Meshtastic range-test mode in the official app. Node 0023 sent every 15 s.
  • WiFi: link quality read from the web UI at each stop.

Results

Green markers: WiFi link, with link quality. Yellow: intermittent or poor WiFi. Red diamonds: LoRa pings once WiFi was gone. LoRa didn't miss a ping for the whole run.

LinkResult
WiFi meshBlocked by a single large building at about 75 m.
LoRaHeld across the whole complex, past 250 m. No missed pings.

That's about what we expected. Without a node in between to give line of sight, one building is enough to stop the WiFi mesh. Compare the lake and open-field tests below to see how much line of sight matters.
