Field tests

What we measured, where, and on which hardware. Every result here is a single link between two or three nodes. A mesh with more nodes reaches further.

Most of these tests ran on earlier hardware (versions 1.0 to 1.2) with a 159 mW LoRa radio. Every version uses the same 500 mW WiFi radio. Version 3 moves to a 1 W LoRa radio. We'll add version 3 results here as we measure them.

Hardware 2.0  /  Software v3_os 0.24.0  /  WiFi 500 mW  /  LoRa 1 W

WiFi and LoRa, obstructed

WiFi and LoRa link test between two nodes in a forest, with 100% line-of-sight obstruction.

Setup

  • Site: Pocahontas State Park, VA.
  • Node 48: placed at ground level (FIG. 01).
  • Node 47: backpack mounted, with the 2.4 GHz and 915 MHz radios connected to an HDCU Yogurt Cup Antenna (FIG. 02).
  • Node 48 remained stationary while node 47 was carried up an existing trail, with link checks about every 50 m after the first 100 m (FIG. 03).
  • WiFi connectivity was checked with route cost in the web UI. LoRa connectivity was checked with text and Codec2 voice.

Results

  • WiFi link cost rose sharply after 150 m, with a full cutoff at 200 m. With no line of sight and heavy vegetation, this is the expected result.
  • LoRa text messaging and Codec2 voice worked cleanly out to about 500 m. The connection became intermittent after 500 m, with a full cutoff at about 560 m.

Notes

  • The LoRa radio is 1 W, but it ran on the Meshtastic Short/Fast setting for this test.
  • We recognise the limits of voice over LoRa. Even so, it was an excellent way to stress-test the LoRa connection in real time.

WiFi and LoRa in an apartment complex

How far the 2.4 GHz WiFi mesh and LoRa reach between buildings, with no nodes in between to give line of sight.

Setup

  • Node 0023, fixed: on a second-floor balcony, with a yogurt-cup antenna (FIG. 06).
  • Node 0022, mobile: stock antennas, carried in a pack (FIG. 07).
  • Site: apartment complex built in 2014, large units of about 1,000 ft² (FIG. 08).
  • LoRa: both radios disconnected from the Nucleus and set to Meshtastic range-test mode in the official app. Node 0023 sent every 15 s.
  • WiFi: link quality read from the web UI at each stop.

Results

Green markers: WiFi link, with link quality. Yellow: intermittent or poor WiFi. Red diamonds: LoRa pings once WiFi was gone. LoRa didn't miss a ping for the whole run.

LinkResult
2.4 GHz WiFi meshBlocked by a single large building at about 75 m.
LoRaHeld across the whole complex, past 250 m. No missed pings.

That's about what we expected. Without a node in between to give line of sight, one building is enough to stop the WiFi mesh. Compare the lake and open-field tests below to see how much line of sight matters.
