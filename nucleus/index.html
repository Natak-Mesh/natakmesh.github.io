Nucleus  /  Version 3

Nucleus mesh radio

Nucleus is a portable mesh networking node. It carries ATAK, voice and messaging over a 2.4 GHz WiFi mesh, and position reports and text messages over a long-range LoRa radio.

Nodes form a mesh automatically when powered on. The network requires no base station, internet connection or cloud account. Phones connect to the access point on any node and reach every device on the mesh.

01Overview

Radio Networks

WiFi Mesh

A self-forming WiFi mesh in the 2.4 GHz band, encrypted with WPA3. It carries ATAK, video and push-to-talk voice, at approximately 30 Mbps between adjacent nodes.

LoRa

A 1 W LoRa radio running Meshtastic. It carries position reports and text messages over long distances, so devices beyond WiFi range remain on the network. It is compatible with standard Meshtastic devices.

02Software

Software

Every Nucleus runs V3 OS, an open-source operating system based on Debian Linux. All settings are managed through a web interface served by the node.

05Range

Range

The coverage of a mesh network depends mainly on node count and placement, not on the transmit power of any single node. Coverage is extended by adding nodes. All figures below are single point-to-point links measured during field tests.

06Source Code

Source Code

V3 OS is published on GitHub under the MIT license. All software it depends on is open source.

  • V3 OSNode operating system. Nodes install updates from this repository through the web interface.
  • Operator manualConfiguration and operation of the node.
  • ReticulumNetworking stack used by Sideband, MeshChat and NomadNet.
  • MeshtasticFirmware for the LoRa radio.
  • OpenTAKServerOpen-source TAK server. Can be installed on a node.
  • ATAKAndroid TAK client. Free of charge; requires a tak.gov account.
