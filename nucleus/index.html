Nucleus  /  Version 3

Nucleus mesh radio

Nucleus is a portable node with two radios: a 2.4 GHz WiFi mesh for full-rate ATAK and voice, and a 915 MHz LoRa radio for position and chat when you're out of WiFi range.

Turn on two or more and they find each other. You don't need a base station or a cloud account. Phones join the node's own access point and see everyone on the mesh.

01What it is

Two meshes in one box

WiFi mesh

An 802.11s mesh on 2.4 GHz, encrypted with WPA3. Babel routes traffic between nodes, so it finds its way across several hops, and ATAK's multicast reaches the whole mesh. It carries anything IP: ATAK, video streams and push-to-talk voice. We measure about 30 Mbps between nearby nodes.

LoRa

A 1 W Meshtastic radio on 915 MHz. It moves small messages a long way. A built-in bridge passes ATAK position and chat (CoT) over LoRa, so a teammate past WiFi range still shows up on the map. Plain Meshtastic radios on the same channel can read and answer your messages.

02What runs on it

Software on the node

Every Nucleus runs V3 OS, our open-source build on Debian 13. One config file drives every service. You change settings in the web UI from the node's access point (http://0042-nucleus.local on node 42), and the node rewrites and restarts only what changed.

Ethernet

Out of the box the Ethernet port is a WAN port. Plug it into a router, a hotspot or Starlink and the node shares that connection with the mesh. In LAN mode it gives addresses to wired devices instead, such as a laptop. The web UI asks for a password over Ethernet. Over the mesh and the access point it doesn't.

Radios off, node on

Each radio has its own switch in the web UI. Turn off the WiFi mesh or the access point, or put the LoRa radio in receive-only mode, and the node keeps running over Ethernet. The mesh and LoRa settings survive a reboot. The access point always comes back on at boot, so you can't lock yourself out.

05Range

On a mesh, range depends on how many nodes you have and where you put them, more than on the power of any one unit. You extend coverage by adding nodes. Every figure below is a single link between two radios from our own field tests.

06Software and source

Open source, top to bottom

V3 OS is on GitHub under the MIT licence. Everything it builds on is an open project you can read and run yourself.

  • V3 OSThe node software. Nodes update themselves from here through the web UI.
  • Operator manualOne page per web UI screen: mesh, messaging, voice, Meshtastic, Reticulum, radios.
  • ReticulumThe network stack behind Sideband, MeshChat and NomadNet.
  • MeshtasticFirmware for the LoRa radio.
  • OpenTAKServerOpen-source TAK server. Can be installed on a node.
  • ATAKThe Android TAK client. Free, needs a tak.gov account.
