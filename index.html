Natak Mesh  /  Tampa, FL

A mesh radio you own

Nucleus puts a 2.4 GHz WiFi mesh and a 915 MHz LoRa radio in one portable box. Two or more units build their own network, with no towers, no internet and no accounts.

Phones join a node's access point and get ATAK, push-to-talk voice, text and Reticulum across the whole mesh. When one node has internet, every node can share it.

Buy Nucleus What's in a Nucleus

01In the field

ATAK without a network

ATAK runs over the WiFi mesh at full rate, with no plugin on the phone. When a teammate walks out of WiFi range, a bridge on the node sends their position and chat over LoRa, so they stay on the map.

  • Push-to-talk voice from a phone browser or an OpenVLM headset.
  • One text inbox over WiFi and LoRa. Plain Meshtastic radios on the same channel can join in.
  • Each radio has its own switch in the web UI, and LoRa can go receive-only. The access point always comes back at boot.

02Own your network

Reticulum on every node

Every Nucleus runs Reticulum as a transport node, so encrypted traffic routes across the mesh and an optional USB RNode radio. Sideband, MeshChat and NomadNet connect to the node over TCP. The software is open source (MIT), and nodes update straight from GitHub.
