Prose

Paragraphs stop at 68 characters so lines stay readable. A text link is underlined in orange and turns orange on hover. Inline code looks like nucleusctl apply --dry-run. A key is Esc. Bold is for the one thing in a paragraph that mustn't be missed.

Muted paragraphs (.muted) carry explanation under a heading. Section bodies are mostly muted, and key sentences stay in full text colour.

  • Lists use a faint marker.
  • Each item is a full sentence or a short fact.
  • Don't repeat the paragraph above as bullets.
  1. Connect to 0009-nucleus-ap.
  2. Open http://0009-nucleus.local.
  3. Change the default passwords.
A blockquote, for quoting someone else. Use it rarely.

Code block

03Sections

Numbered sections

Each section is a .sec with a label rail (.sec-label: an orange number and a caps label) and a body (.sec-body). Under 54 rem the rail moves above the body. Number sections in page order, starting at 01.

<section class="sec" aria-labelledby="ports">
  <div class="wrap">
    <p class="sec-label"><span>03</span>Interfaces</p>
    <div class="sec-body">
      <h2 id="ports">Ports and radios</h2>
      ...
    </div>
  </div>
</section>

Two columns (.cols-2)

WiFi mesh

An 802.11s mesh on 2.4 GHz, encrypted with WPA3 (SAE). Babel routes traffic between nodes, and smcroute forwards multicast across them.

Access point

A separate 5 GHz access point for phones and laptops, named after the node: 0009-nucleus-ap on node 9. It always comes back on at boot.

Figure and text (.split)

Ethernet

Out of the box the Ethernet port is a WAN port: a DHCP client that shares its internet connection with the mesh. In LAN mode it serves DHCP to a wired device instead. Over Ethernet the web UI asks for a password. Over the mesh and the access point it doesn't.

Radios off, node on

The WiFi mesh, the Meshtastic radio and the access point each have their own switch. With them off, the node stays reachable over USB-C, Ethernet or the console.

04Tables

Tables, not cards

Specs, services and comparisons go in tables. Row headers are <th scope="row"> in muted text. Values that are numbers, units or identifiers get class="v" (mono). Wrap wide tables in .table-scroll.

05Figures

Figures

Photos sit in a 1 px frame on a light ground, with a mono caption that starts with a figure number. Number figures in page order. Only the black v3 enclosure appears outside the manual. Every image has width, height and descriptive alt. Every image except the hero also has loading="lazy" and decoding="async".

06Blocks

Buttons, notes and the buy block

Buttons

Buy Nucleus Secondary Text link

One orange button per screen at most. It's for buying. Everything else is a text link or .btn-line. Tab through this page to see the focus ring: 2 px orange, offset 3 px. On orange buttons it switches to light.

Note (.note)

Not yet tested Use a note for a limit or an untested claim. Say it plainly, with what we know and what we haven't measured.
