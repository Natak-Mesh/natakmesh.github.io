About Natak Mesh

Learn about our company, our mission, and the innovative networking solutions we provide.

Our Story

Natak Mesh was originally inspired by the Rocket M5 MANET builds done by the team at teamawarenesskit.org. We used those solutions for a while but wanted something simpler to set up and use.

Our journey led us to Meshtastic, but the extremely low throughput pushed us back towards WiFi-based solutions. We worked for most of a year on a HaLow WiFi build, but the currently available low-power radios did not have enough of a range advantage to make up for the low throughput.

We built a WiFi mesh core focused on throughput and reliability. The result is the Nucleus — a single platform with WiFi mesh and LoRa that can be configured for different use cases.

Communication Philosophy

The Nucleus was built to solve a real problem for ATAK users: LoRa mesh networks have great range but are too slow for situational awareness (SA), voice, video, and file transfers at the speed ATAK was designed for. The Nucleus puts ATAK on a high-speed WiFi mesh and adds a LoRa CoT bridge for extended range — giving you both speed and distance in one package.

Each node provides multiple communication capabilities that can be used independently or together:

  • ATAK Over WiFi Mesh: Native SA, chat, voice, and video at full speed over 802.11s mesh — the primary use case
  • LoRa Extended Range: SA and chat forwarding beyond WiFi via Meshtastic LoRa
  • Reticulum Integration: Non-IP based communications for privacy-focused applications
  • Standalone Meshtastic: Independent LoRa communication compatible with the Meshtastic ecosystem

Use one or all communication methods as needed. No vendor lock-in.
