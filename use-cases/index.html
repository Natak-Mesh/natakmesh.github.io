Use cases

A Nucleus node includes a 2.4 GHz WiFi mesh radio, a LoRa radio, an Ethernet port and a WiFi access point. Two optional expansion modules connect to its USB-C port: a WiFi HaLow radio, which provides an additional IP mesh in the 900 MHz band, and an RNode, which provides an additional Reticulum interface over LoRa. Each interface is enabled and configured independently, so the same hardware serves a wide range of applications.

The examples below are not fixed operating modes. Each is a combination of standard settings, and most can be combined on the same node or within the same network. Each function is described in detail on Field operations.

02Examples

Examples

ATAK

The default configuration. ATAK operates over the 2.4 GHz WiFi mesh at full speed, with push-to-talk voice and messaging on the same network. Devices beyond WiFi range remain on the map through the LoRa fallback.

ATAK · LoRa fallback · Push-to-talk

Meshtastic only

With the 2.4 GHz WiFi mesh disabled, the node operates as a standard Meshtastic node, and messages are sent from any phone or laptop on its access point. It interoperates with any Meshtastic radio on the same channel.

Messaging and Meshtastic

Private Reticulum network

A group of nodes forms a private, end-to-end encrypted network with no carrier, no accounts and no phone numbers. Reticulum operates over the 2.4 GHz WiFi mesh and Ethernet. Where neither is available or wanted, an optional RNode module provides a Reticulum link over LoRa.

Reticulum

Links between sites

Meshes at separate locations are joined into one private network over any available internet connection, optionally inside a Tailscale network. Each site continues to operate locally if the connection is lost.

Links between sites

HaLow mesh

An optional WiFi HaLow module provides an IP mesh in the 900 MHz band, as an additional link alongside or in place of the 2.4 GHz WiFi mesh. Throughput is substantially lower than the 2.4 GHz WiFi mesh.

HaLow mesh

Low emission

The 2.4 GHz WiFi mesh is disabled and the LoRa radio only listens. Messages are sent over an optional RNode module, and the node transmits only when the operator sends a message. Reduced emissions lower the probability of detection, but do not prevent it.

Threat model

Hard-wired links

Nodes are connected by Ethernet cable, or by fiber for longer distances and electrical isolation, with all radios disabled. The link produces no RF emissions.

Reticulum

Internet sharing

One node connected to a router, mobile hotspot or Starlink terminal shares that connection with every node and device on the mesh. No configuration is required on the other nodes.

Internet sharing

Ordering

A mesh network requires at least two nodes. Measured link ranges are documented in field tests, and the protections and limits of Nucleus are described in the threat model.
