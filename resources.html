Mesh Networking Software

Meshtastic

Long-range radio messaging. Works with the LoRa radio in Nucleus devices. Encrypted text messages up to several kilometers away.

Visit Meshtastic

Reticulum

Encrypted messaging and file sharing over mesh networks. Works automatically when you connect to Nucleus devices. Supports apps like MeshChat and Sideband.

Visit Reticulum

TAK Resources

Android Team Awareness Kit (ATAK)

Maps, messaging, and location sharing for Android. Works over WiFi mesh and LoRa radio on Nucleus devices. Requires account to download.

Download ATAK

OpenTAKServer

Open-source TAK server that runs on Nucleus devices. Handles ATAK client connections, video streams, and data packages across the mesh.

View Documentation
